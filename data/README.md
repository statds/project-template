# Project Data

Document each data source used in the project. For each source, record:

- the source and access link;
- the date accessed or collected;
- the population, time period, and geographic coverage;
- the observational unit and important variables;
- the license, terms of use, and any restrictions;
- known missingness, exclusions, or other limitations.

Keep source files unchanged and distinguish them from cleaned or derived
files. Explain how derived data were created and provide code when practical.

Commit data only when redistribution is permitted and the files are small and
appropriate for Git. Do not commit private, sensitive, or restricted data. For
large or restricted data, document how collaborators with permission can
obtain it and keep the files outside this repository.
